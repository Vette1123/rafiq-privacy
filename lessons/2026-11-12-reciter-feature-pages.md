# Reciter and feature pages, install-page hubs

## What

Added `reciters/` (index + 42 pages) and `features/` (index + 6 pages): Arabic-only, generated by
`pnpm site:pages` in the Rafiq app repo, never edited here. The Arabic install page now links the two
hubs (`go.copy.json` `hubs`, a `{{HUBS}}` slot in `go.template.html`), the English page links features.

## Mistakes

**Pages carry no language toggle copy, but the shared header has one.** lang-pick.js flips `lang` to
the stored or browser language, which would turn an Arabic page LTR. Fixed by `data-alt` on the install
page URL: a reader who chose English is sent to /go, anyone else (and every crawler) stays Arabic.

**Edited a generated page's source and forgot the rebuild.** build-go.mjs reads `.` as the repo, so it
only works from the site checkout; run it there and check `git status` in the portfolio too.

## What worked

- Reuse of partials (head, theme, header, footer.ar, switches) and the masareef shell: no new design.
- sitemap.xml untouched: the portfolio lists the pages from content/rafiq-pages.json.

## Rules

- Never edit `reciters/` or `features/` by hand; edit the generator in the app repo.
- A copy change to the hubs line goes in go.copy.json, then `node scripts/build-go.mjs`.
